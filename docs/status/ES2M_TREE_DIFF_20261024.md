1. 完整上游已保存於獨立唯讀來源鏡像；不得把鏡像目錄當作可直接部署的 Runtime。
2. `MODIFIED_UPSTREAM` 須先做逐檔 diff、相依性分析與測試，再決定採用上游、保留 KING 或建立 adapter。
3. `NEW_UPSTREAM` 先分類為文件、地圖／NPC、技能／戰鬥、核心 mudlib、資料／二進位檔；只有低衝突項目可批次整合。

5. Original ES2 原始保存層、ES2M 來源鏡像、KING Expansion Runtime 必須分層；來源證據不足時標記 UNKNOWN。
6. 本報告不代表 Runtime、Docker、Actions 或 E2E 已 PASS。
