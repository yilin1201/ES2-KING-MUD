# ES2M Evidence Priority

Effective project evidence order:

1. Original ES2 source
2. ES2M
3. Archived / Historical Evidence
4. Reconstruction

ES2M is the project name for `wolfer168/es2-webmud`.

ES2M is first-priority supplemental evidence whenever the current Original source is silent or incomplete. ES2M does not automatically become Original: provenance must remain explicit.

## Labels
- `SOURCE_BACKED`: verified directly against Original ES2 source.
- `ES2M_REFERENCE`: present in ES2M but not verified in the current Pinned Original.
- `HISTORICAL_EVIDENCE`: external archived/gameplay evidence.
- `RECONSTRUCTION`: implementation created only after higher-priority evidence is exhausted.

## Runtime rule
An ES2M_REFERENCE may be used as the preferred recovery specification, but must not be described as Pinned Original. Existing ES2-KING Canon remains preserved unless the user explicitly changes it.
