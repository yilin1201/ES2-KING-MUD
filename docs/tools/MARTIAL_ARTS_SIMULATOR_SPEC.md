# 武功招式模擬器－正式規格（介面基準）
 
> 狀態：ES2-KING 通用模擬器介面設計規格；不是 Original ES2 武學證據，也不是已部署的遊戲功能。
> 核准基準：使用者於 2026-10-03 確認的完整聊天室互動版（移除標題版本編號與副標）。
> 變更範圍：模擬器介面與輸出格式；不得自動修改遊戲武功、傷害、內力或存檔。
 
## 一、標題及外觀
- 唯一標題：**武功招式模擬器**。不得顯示 V9 等版本編號，不顯示「名稱加寬・精簡選單・即時戰鬥預覽」等副標。
- 深色背景、金黃色標題及邊框、黑色戰鬥文字預覽框；手機直式介面優先。
- 顏色清單（選單採單字，避免截斷）：紅 #ff555b、橙 #ff9a45、黃 #ffe55b、綠 #4cdd76、藍 #559cff、靛 #8980ee、紫 #d877e9、灰 #a9a9b3、白 #ffffff。
- 名稱外框選項及短標籤：`「」`、`【】`、`無`；輸出時分別包覆文字或不加外框。
 
## 二、區塊 1：武功基本設定
- 武功名稱：單獨一行，預設「傲劍訣」。
- 第二行三欄：名稱顏色、名稱外框、對手名稱。預設黃、「」、瞎眼老太婆。
- 招式數量：滑桿選擇 1–12 式，預設 6 式；調低數量後選中式數不得超出範圍。已編輯而暫時隱藏的招式設定不應被清除。
 
## 三、區塊 2：一般招式設定
- 依招式數量顯示可點選招式卡片；點選某一式後編輯其專屬設定並切換單式預覽。
- 每式獨立保存：招式名稱、名稱顏色、名稱外框、前奏敘述及其文字顏色、動作敘述及其文字顏色。
- 招式名稱／顏色／外框**同一行**，比例約 50%／22%／28%，欄位間距縮小；顏色選單單字、外框選單短標籤，選中值不得呈現「…」。手機版需檢查「忠」、「劍領風騷」等文字可見性。
- 前奏與動作各自獨立一行：左側約 76px 的顏色選單，右側可自動增高的多行文字輸入框；顏色選擇與相應敘述必須並排。
- 預設前六式：忠／綠、武／紅、義／紫、德／青、狂／金黃、情／藍；名稱預設【】；後續式數僅為可編輯範例，不得當作 Original ES2 考證。
 
## 四、區塊 3：連續施展設定
- 「無連續特攻」與「有連續特攻」使用**同一行**的雙選項切換，預設無連續特攻。
- 選擇「有連續特攻」才顯示專屬設定；切回無連續特攻時保留已輸入內容。
- 專屬設定第一行三欄：連續特攻名稱／名稱顏色／名稱外框，比例約 **50%／22%／28%**；名稱預設「劍領風騷」，顏色預設黃，外框預設「」。顏色及外框短標籤必須完整顯示，不得以「…」替代。
- 連續特攻前奏敘述：左側約 76px 顏色選單、右側可編輯多行文字；預設白字「你猛然提氣，劍意凝聚，施展出華麗的連環劍舞，」。
- 連續特攻動作敘述：左側約 76px 顏色選單、右側可編輯多行文字；預設紅字「無數劍光交錯，化作連綿不絕的劍氣直射向」。
- 專屬前奏及動作屬於**連續特攻本身**，不能誤當一般招式的開場或收尾，也不能覆蓋每式的前奏與動作。
 
## 五、區塊 4：戰鬥文字預覽與複製
- 預覽模式使用同一行雙選項：「單式預覽」及「連續 N 式」，N 連動招式數量。
- 單式預覽只顯示目前選中招式；連續模式依順序顯示 N 式。
- 只有當「有連續特攻」且預覽模式為「連續 N 式」時，才先顯示一次專屬連續特攻文字，接著顯示 N 式各自的文字。
- 一般招式輸出：`你施展{武功名稱及外框}中的招式{招式名稱及外框}！`；下一行依序拼接該式前奏、該式動作、對手名稱及「！」。
- 專屬連續特攻輸出：`你施展{武功名稱及外框}中的連續特攻{連續特攻名稱及外框}！`；下一行依序拼接專屬前奏、專屬動作、對手名稱及「！」。
- 預覽須依各欄選擇的顏色即時更新；招式之間以分隔線區分。
- 「複製戰鬥文字」按鈕複製目前模式的純文字結果，不含介面樣式或 ANSI 顏色碼；複製內容應與目前預覽的文字及順序一致。
- 模擬器不得自行附加 `-kee max` 或虛構攻擊傷害；如未來新增數值欄位，應另外建立版本及來源規格。
 
## 六、驗收條件
1. 標題僅「武功招式模擬器」，沒有版本號、副標。
2. 一般招式與連續特攻的名稱／顏色／外框均為同列，比例 50／22／28；短選單值完整顯示。
3. 一般招式及連續特攻的前奏／動作皆為左側顏色＋右側輸入。
4. 連續特攻切換鈕同列；關閉時不顯示專屬設定，重新啟用時保留原內容。
5. 1–12 式可獨立編輯；單式及連續預覽與複製結果一致。
6. 所有功能僅屬通用文字模擬；現有 `docs/tools/aojian_combat_simulator.html` 與 `docs/tools/zhen_aojian_combat_simulator.html` 以及 Runtime 武學均不受本次規格提交影響。
