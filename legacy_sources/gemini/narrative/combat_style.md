# Gemini 高階戰鬥敘事規則

> `[Legacy Source: Gemini]` `[Narrative Reference]`
>
> 這份資料不是武功清單，而是從 Gemini 舊資料中抽出的「戰鬥怎麼寫才有 ES2-KING 味道」。後續可作 Narrative Engine（敘事引擎）參考。

## 1. 招式不要從傷害數字開始

高階招式應先讓玩家「感覺到它要來了」。

常見順序：

```text
人物狀態改變
→ 眼神／呼吸／真氣改變
→ 武器或身體產生異象
→ 周遭環境回應
→ 招式真正爆發
→ 敵方反應與結果
```

例如明鏡止水不是直接出現冰傷害，而是先出現死寂、冰晶、劍鞘凝霜、雙瞳雪魄化，再進入真正攻防。

## 2. 每套武學必須有自己的視覺語言

不要所有大招都只寫「神光、爆炸、虛空破碎」。

### 目前已形成的辨識系統

- **霸天煉體訣**：鮮血、霸體、暗金／金色、受創後力量反升。
- **明鏡止水**：六角冰晶、雪花青芒寒光、水銀霜白、極光青、死寂。
- **如來神掌／歸墟神輪**：純白、曼陀羅、佛光、神輪、越強越安靜。
- **太極玄虛**：紫氣、陰陽、圓轉、卸力、借力。
- **哭笑門**：青邪、殘影、毒霧、怪笑、情緒與經脈干擾。
- **渾天寶鑑**：天象、自然色彩、天地變化、宇宙層次。
- **古霄**：沉黑、暗金、重壓、斬裂、霸道。
- **飛雲**：玉白、流雲、幻影、陣紋、迅捷。

## 3. 高手必須「看得懂」武功

同一場戰鬥中，不同人物的旁觀反應不能只是輪流說「好強」。

### 人物觀戰人格

- **李雲霄**：從法則、本源、神魂、術道、劍意判讀。
- **歐陽玄**：從陰陽、道家造化、借力、天地氣機判讀。
- **梅影風**：從劍境、寒意、心境與武者純度判讀。
- **劉乙忘玄**：用誇張、幽默、江湖口吻呈現威力，讓高階戰鬥仍有人味。

觀戰者的評論本身就是角色塑造的一部分。

## 4. 最強不等於最吵

Gemini 舊資料中最值得保留的方向之一：

**越接近概念／神魂／法界級招式，反而可以越安靜。**

例如萬相歸墟的壓迫感來自：

```text
五感消失
→ 意識停滯
→ 護體與識念失效
→ 世界只剩純白
```

而不是只靠「爆炸範圍比上一招大十倍」。

## 5. 戰鬥結果必須先由遊戲系統判定

敘事引擎不能自己決定誰死、誰中招。

正確流程：

```text
戰鬥引擎
  ↓
命中／格擋／閃避／傷害／狀態判定
  ↓
取得實際結果
  ↓
Narrative Engine
  ↓
依人物、武學、境界、場景輸出文字
```

例如：
- 系統判定「閃避成功」後，明鏡止水才寫成肉身本能側移。
- 系統判定「霸體減傷」後，霸天煉體訣才寫成金色霸體硬抗。
- 系統判定「控制成功」後，青邪杖法才寫經脈受制或退路被封。

## 6. 高階角色不能靠兩行文字秒殺一切

使用者在 Gemini 後期明確修正：李雲霄對 King 的高階戰鬥不能太快結束，至少應經過多輪招式、應對、霸體承傷、感悟與反制，再逐漸形成傷勢。

因此對「宗師以上／神級」戰鬥建議使用階段制：

```text
試探
→ 招式交換
→ 破解第一層防禦
→ 角色調整策略
→ 核心武學啟動
→ 重創／反轉
→ 終極招式
→ 結果
```

這樣人物強度來自戰鬥智慧與機制，而不只是 HP 數字。

## 7. 受傷必須影響人物的下一個行動

不要寫成：

```text
受到重傷
下一行完全沒事地放大招
```

應改為：
- 呼吸紊亂。
- 握劍手勢改變。
- 真氣運轉受阻。
- 霸體介入修復。
- 人物因受傷改變戰術。

如此才能讓「越戰越勇」「瀕死反擊」「宗師經驗」真正有意義。

## 8. 人物性格要進入招式文字

同一招由不同人施展，文字應不同。

- 古飛揚：狂、霸、直接迎強敵。
- 李雲霄：先看穿、再出手，從容但壓迫。
- 梅影風：靜、冷、劍心不亂。
- 劉乙忘玄：詭、怪、似真似假。
- 歐陽玄：不爭先手，以圓轉化解。

## 9. 狀態轉換要有「事件感」

古飛揚 → 李雲霄是最佳模板。

不要只顯示：

```text
古飛揚死亡。
李雲霄生成。
```

而應拆成：

```text
肉身敗亡
→ 神魂未滅
→ 世界／神器出現回應
→ 兩世記憶共鳴
→ 神魂融合
→ 武學重新載入
→ 視覺標誌出現
→ 新形態正式登場
```

這類事件可用於轉生、覺醒、破境、神器認主與 Boss 第二階段。

## 10. 後續 Narrative Engine 建議輸入欄位

```text
人物性格
武學
招式
境界
武器
生命比例
受傷部位
攻防結果
目前狀態
敵方類型
場景
旁觀人物
戰鬥階段
```

再由模板決定文字強度。

### 敘事層級
- 普通交手：短、清楚、ES2 武俠感。
- 宗師交鋒：武理、氣機、拆招。
- 重傷／絕境：肉身與真氣後果。
- 境界壓制：威壓、心境、戰術差距。
- King／特殊收藏角色：法界、神魂、天地異象與高階玄幻演出。

**原則：高階敘事可以玄幻，但 Original ES2 的底層戰鬥判定不能被旁白取代。**
