# Gemini 舊資料重點整理

> `[Legacy Source: Gemini]` `[ES2-KING Expansion]`
>
> 本目錄整理使用者先前在 Gemini 中累積的 ES2-KING 設定重點。內容來源以使用者提供的 TXT 檔案為主，目的不是把整段聊天原樣搬入 GitHub，而是抽取可長期保存、可再利用的角色、武學、戰鬥敘事與修正紀錄。

## 使用原則

1. **Original ES2 與 Gemini 延伸資料分離。** 本目錄內容不得直接標示為 Original ES2 原版設定。
2. **使用者明確確認過的設定可進一步升格為 Project Canon。**
3. **Gemini 曾自行補寫或推演的數值、技能效果、世界觀描述，不自動視為正式設定。**
4. 對第三方作品人物／武學，保留名稱與使用者指定內容；小說原文效果另行考證，不以 AI 推測補成原著設定。
5. 若 Gemini 舊資料與使用者後續修正衝突，以**後續修正**為準。

## 本批整理內容

- `characters/summary.md`：重要人物、性格、定位與戰鬥語言。
- `martial_arts/summary.md`：核心武功、招式與戰鬥表現重點。
- `narrative/combat_style.md`：Gemini 最有價值的高階戰鬥敘事規則。
- `corrections/exclusions.md`：使用者已否定或要求停止沿用的舊詞與舊設定。

## 與正式資料庫的關係

```text
Original ES2
   │
   ├── original_es2/               # 原作考證
   │
   └── ES2-KING Expansion
          │
          ├── king_library/        # 已確認的私人收藏／正式擴充
          │
          └── legacy_sources/
                 └── gemini/       # Gemini 舊資料抽取與版本沿革
```

Gemini 資料庫的用途是「保存優秀舊設定與敘事」，不是直接凌駕目前正式 Project Canon。
