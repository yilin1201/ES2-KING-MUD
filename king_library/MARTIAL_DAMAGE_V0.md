# ES2-KING｜武學傷害 V0 統一設定指令

## 定義
「武學傷害 V0」是可指定套用於某套武學及其旗下招式的**設定指令**，不是招式名稱、招式類型，也不是宣稱目前所有武學已經使用的遊戲預設值。

## V0 參數
| 設定項目 | 指定範圍 |
| --- | ---: |
| 攻擊加成 | +10～20 |
| 內力係數 | +10～20 |
| 防禦效果 | 0～20 |

## 使用方式
使用者指定「〈武學名稱〉，武學傷害 V0」時，針對該武學旗下招式，依各招式特性，在上述範圍內分配三項參數。未指定的其他武學不得連帶更改。

## 執行原則
1. 保留指定武學既有招式名稱、順序、敘述、顏色與原有特效；僅調整經使用者指定的傷害相關參數。
2. 實際寫入程式前，先查明目前 Runtime 戰鬥引擎如何解讀 `attack`、`force`、`defense`，避免誤用防禦欄位；沿用既有命中、防禦、內力與精力消耗機制。
3. 此 V0 是 ES2-KING 自訂配置標準，不能標記為已考證的 Original ES2 或 ES2M 原始係數。
4. 本文件建檔不等於已對任何武學套用，也不代表 Static 或 Runtime 測試通過。後續套用時須記錄具體招式數值及測試證據。

## 指令範例
「傲劍訣，武學傷害 V0」：僅對傲劍訣的招式分配攻擊 +10～20、內力 +10～20、防禦 0～20；其他武學不受影響。
