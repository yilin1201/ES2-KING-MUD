# 霸天煉體訣

> `[ES2-KING Project Canon]`
> `[King Private Library]`
> `[Martial Art]`

## 核心定位

霸天煉體訣為古飛揚前世所修習、並於轉生為李雲霄後繼續推演完成的煉體武學。

其核心演進分為兩個階段：

- **霸天煉體訣・兆**：古飛揚時期尚未完成的階段。
- **霸天煉體訣・極**：李雲霄轉生後，在前世修煉基礎上進一步推演完成的究極完整版。

「兆」與「極」並非單純的招式強弱分級，而代表霸天煉體訣由未完成走向完整化的武學進程。

---

## 霸天煉體訣・兆

### 使用者

**古飛揚**

### 定位

古飛揚前世所掌握的霸天煉體訣尚未完成，但已具備極強的肉身淬鍊、傷勢修復與越戰越勇特性，並能初步踏入**不滅金身**的領域。

### 戰鬥機制

戰鬥中，隨著古飛揚肉身受到損傷，霸天煉體訣會逐步受到激發：

**受傷 → 肉身逐步修復 → 戰意與戰力提升 → 再度受創 → 功法再次激發 → 越戰越勇**

因此，古飛揚在持續戰鬥與承受傷勢的過程中，能逐步恢復受損肉身並提升自身戰鬥能力。

### 不滅金身・未完成

古飛揚能以「兆」發動不滅金身，但此時的不滅金身仍屬於**未完成形態**。

其肉身修復與越戰越勇能力具有極限，並非絕對不死。

當遭遇實力真正凌駕於古飛揚之上的高手，若承受的傷害速度、破壞程度或致命攻擊超越「霸天煉體訣・兆」所能承受與修復的極限，古飛揚仍可能戰敗並最終陣亡。

> **修復，不等於不死；不滅金身之「兆」，仍有其極限。**

---

## 古飛揚陣亡與神魂合一

古飛揚陣亡後，並非單純復活。

其神魂最終與轉生後的**李雲霄**完成合一，使前世古飛揚的武道底蘊與李雲霄融為一體。

### 神魂合一後的能力基準

以古飛揚全盛時期的綜合能力作為基準：

- **古飛揚：100%**
- **神魂合一後的李雲霄：150%**

亦即：

> **李雲霄完成神魂合一後，其綜合能力為古飛揚全盛時期增加 50%。**

此 50% 定義為角色整體基礎能力層級的提升，而非單一招式傷害直接乘以 1.5。

神魂合一帶來的角色能力提升，與後續「霸天煉體訣・極」的武學完成化屬於兩個不同層次，不應混為同一項加成。

---

## 霸天煉體訣・極

### 使用者

**李雲霄**

### 定位

李雲霄在古飛揚前世修煉成果之上，繼續推演並完善霸天煉體訣，最終突破原有極限，使整套武學真正完成，形成：

> **霸天煉體訣・極**

「極」代表霸天煉體訣的**究極完整版**，而非單純提高威力的強化形態。

### 不滅金身・完整化

「兆」與「極」最大的境界分水嶺，在於**不滅金身由未完成走向完整化**。

因此正式演進為：

```text
古飛揚
  │
  ▼
【霸天煉體訣・兆】
  │
  ├─ 肉身淬鍊
  ├─ 傷勢逐步修復
  ├─ 越戰越勇
  ├─ 瀕死反撲
  └─ 不滅金身【未完成】
             │
             │ 戰敗／陣亡
             ▼
        古飛揚神魂
             │
             │ 與轉生後李雲霄合一
             ▼
           李雲霄
     【基礎綜合能力 150%】
             │
             │ 前世武道基礎繼續推演
             ▼
【霸天煉體訣・極】
             │
  ├─ 霸天煉體訣究極完整版
  ├─ 肉身極境
  ├─ 絕境重生
  ├─ 戰意不滅
  └─ 不滅金身【完整化】
```

## Canon 規則

1. **兆＝古飛揚時期尚未完成的霸天煉體訣。**
2. **極＝李雲霄轉生並完成神魂合一後，在前世基礎上進一步推演完成的究極完整版。**
3. 古飛揚的「兆」具備隨身體損傷逐步修復及越戰越勇的能力，但仍存在承受與修復極限，遭遇真正高手仍可能陣亡。
4. 古飛揚陣亡後，其神魂與李雲霄合一；神魂合一後李雲霄的綜合基礎能力，以古飛揚全盛時期 100% 為基準，提升至 **150%**。
5. 150% 為角色整體基礎能力層級，不代表所有招式固定造成 1.5 倍傷害。
6. 神魂合一的 50% 能力提升與「霸天煉體訣・極」的武學完成化為兩個不同層次。
7. 「兆」的不滅金身為未完成形態；「極」使不滅金身達到完整化。
8. 「極」即霸天煉體訣的最終完成態；除非使用者日後另行定案，不自行增設「極」以上的新階段。
