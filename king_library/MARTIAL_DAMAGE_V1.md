# ES2-KING｜武學傷害 V1 統一設定指令

## 定義
「武學傷害 V1」是可指定套用於某套武學及旗下招式的**設定指令**，不是最終實際傷害公式，也不代表全部武學自動升級。V0 原始標準保留於 `MARTIAL_DAMAGE_V0.md`。

## V1 參數
| 設定項目 | V0 原範圍 | V1 新範圍 |
| --- | ---: | ---: |
| 攻擊加成（attack） | +10～20 | +20～40 |
| 內力係數（force） | +10～20 | +20～40 |
| 防禦效果（defense） | 0～20 | 20～40 |

## 使用方式
使用者指定「〈武學名稱〉，武學傷害 V1」時，僅針對該武學旗下招式，依招式特性在 V1 範圍內分配 attack、force、defense 三項數值。未指定武學仍維持原有設定。

## 執行原則
1. 不修改 V0 正式基準檔，不自動覆蓋已完成或凍結的武學。
2. 保留招式名稱、順序、文字敘述、顏色及原有特效；只調整明確指定的傷害參數。
3. 原始戰鬥引擎中 attack 主要影響命中，force 參與內力力道計算，defense 影響下一次對手攻擊判定；三者不是直接相加的傷害倍率。
4. 實際套用前記錄各招式的 V0→V1 係數、受影響檔案，執行靜態檢查與普通玩家隔離 Runtime 傷害測試。
5. V1 為 ES2-KING 自訂配置，非 Original ES2 或 ES2M 原始係數；建立此標準不代表任何武學已套用或 Runtime 已驗證。

## 指令範例
「傲劍訣，武學傷害 V1」：只將傲劍訣各招式的攻擊、內力、防禦係數分配到 20～40；其他武學不受影響。
