# King Private Library｜創世神 King 私人收藏資料庫

> 狀態：`[ES2-KING Project Canon]`

本目錄保存創世神 **King** 的私人收藏與跨世界擴充內容。

## 最高原則

- **Original ES2 是遊戲底層世界與規則骨架。**
- 本目錄內容不屬於 Original ES2，不得反向標記為 ES2 原版資料。
- 非 ES2 原創人物、武學、神兵與終極招式，可依 King 個人喜好在此備存。
- 一般玩家不會因為資料存在本目錄，就自然取得或遇到這些內容。
- 是否將收藏人物召喚至天朝帝國、授予武學或創造神兵，由最高權限的創世神 **King** 決定。

## 創作方向

ES2-KING 的底層遊戲骨架維持 ES2；高階擴充戰鬥可加入武俠式武學邏輯，以及更高層次的玄幻武道氣勢、境界壓迫、人物反應與戰鬥旁白。

## 資料標記

- `[King Private Library]`：King 私人收藏。
- `[External IP Reference]`：取材或參考第三方作品的人物／武學／設定。
- `[ES2-KING Expansion]`：ES2-KING 新增或重新設計內容。
- `[Project Canon]`：已由使用者明確確認的正式專案設定。
- `[Novel Verified]`：後續已逐項以小說文本完成考證的資料。
- `[Needs Novel Verification]`：已收錄，但原著細節仍待逐項考證。

## 目前分類

- `characters/`：King 收藏人物
- `weapons/`：King 收藏神兵／武器
- 後續可增加 `martial_arts/`、`ultimate_moves/`、`narrative/` 等分類。
