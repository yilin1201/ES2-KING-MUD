# 青邪宮・大邪七損刀（Seven-Damage Blade）

> 分類：ES2-KING Expansion / 正式程式設計資料  
> 角色：青邪魔尊・劉乙忘玄（Liu yiwangxuan）  
> 門派：青邪宮・哭笑門  
> 內功基礎：哭笑門心法  
> 搭配招式／狀態技：大邪金身

## 武學關係（正式設定）

青邪宮 → 哭笑門 → 哭笑門心法（內功） → 大邪金身（搭配招式／狀態技）

「大邪金身」不是獨立內功；它是使用哭笑門心法內功後可搭配施展的招式／狀態技。其實際反震、減傷、護體或其他效能，須以 Gameplay 影片或 Original LPC 證據逐項確認，不預設數值。

## Evidence Boundary

本文件已列入 ES2-KING 正式設計資料，但不宣稱以下七式、perform 指令與數值機制為 Original ES2 已確認史料。實際 Gameplay 影片已觀察到青邪宮／劉乙忘玄相關武學線索與「大邪金身」；大邪七損刀完整七式仍需 Original LPC 或 Gameplay Evidence 驗證。後續若取得原始證據，以 Original Evidence 優先修正本設計。

武學核心：招式狠辣刁鑽，以「損皮 → 損肉 → 損筋 → 損骨 → 損脈 → 損氣 → 損魂」形成逐層破壞體系。

## 第一損：損皮・雷霆震不還
- 指令：`perform sunpi` / `perform leiting`
- 演繹：劉乙忘玄身形飄忽，反手握刀自下盤死角如毒蛇出洞般逆撩而上；刀鋒未至，凌厲薄刃氣勁已如細碎電芒撕裂空氣。
- 機制【破皮碎甲】：專削肌膚表層與防具薄弱處，撕裂第一道物理防禦。
- 機制【破防流血】：命中後造成流血與劇痛硬直，使其下盤發虛。

## 第二損：損肉・傲笑傲天魔
- 指令：`perform sunrou` / `perform aotianmo`
- 演繹：劉乙忘玄仰天怪笑，怪嘯擾亂心神，刀光自不可思議角度斜切腰腹或脅下深層血肉。
- 機制【爛肉化膿】：螺旋絞殺刀勁深入肌理。
- 機制【體能瓦解】：削減體力上限，使動作、攻速與閃避下降。

## 第三損：損筋・寒霜透骨
- 指令：`perform sunjin` / `perform tougu`
- 演繹：刀鋒泛起幽綠刺骨的大邪陰煞之芒，極速點刺周身關節大穴，寒毒沿手足大筋滲透。
- 機制【抽筋錯節】：針對手筋、腳筋與關節韌帶。
- 機制【強制定身】：設計為 2～3 回合 Busy，限制身法。

## 第四損：損骨・笑哭不得也
- 指令：`perform sungu` / `perform xiaoku`
- 演繹：劉乙忘玄將大邪魔元灌注刀脊，以刀背或重勁猛烈砸擊骨骼。
- 機制【碎骨斷樑】：沉重暗勁震擊骨骼。
- 機制【重傷骨折】：設計為降低 Parry 與力量判定。

## 第五損：損脈・哭笑無常刀
- 指令：`perform sunmai` / `perform wuchang`
- 演繹：刀光忽明忽滅、似悲似喜；漆黑刀煞沿奇經八脈逆流。
- 機制【斷脈逆血】：破壞內功周天循環。
- 機制【走火入魔】：阻斷真氣／內力回復、逼退運功狀態並造成內力反噬。

## 第六損：損氣・大邪絕息斬
- 指令：`perform sunqi` / `perform juexi`
- 演繹：大邪真氣向內塌縮，絕息魔刃直貫心脈。
- 機制【抽乾精元】：設計為吞噬目標護體罡氣與真元。
- 機制【破滅氣海】：損耗真元上限並暫時限制 Perform。

## 第七損：七損合一・命魂俱滅
- 指令：`perform qisun` / `perform destroy`
- 定位：七損終極奧義。
- 演繹：「一損皮！二損肉！三損筋！四損骨！五損脈！六損氣！七損魂！」七道刀煞合一，直攻神魂命元。
- 機制【絕對純粹真實傷害】：設計為高階穿透型終極傷害。
- 機制【七重負面引爆】：引爆前六損累積狀態。
- 機制【自損代價】：設計值為施術者扣除自身 15% 氣血精力；低生命目標可進入斬殺判定。

## 實作與考證規則
1. 本七式已作為 ES2-KING Expansion 正式設計基準。
2. `2～3 回合 Busy`、`15% 自損`、穿透／斬殺等為 Expansion 設計數值，不得回寫為 Original ES2 史實。
3. 「大邪金身」正式定位為「哭笑門心法」內功可搭配施展的招式／狀態技，不得實作成另一套獨立內功。
4. 大邪金身的反震、減傷、護體等實際效能與數值，待 Gameplay／Original LPC 證據確認。
5. 若日後找到 Original LPC、原始 Skill ID、perform 或戰鬥輸出，採 preserve → understand → rebuild → expand 原則整合。
6. 不以本文件補造 Original Evidence；未確認項目保持 UNKNOWN。
