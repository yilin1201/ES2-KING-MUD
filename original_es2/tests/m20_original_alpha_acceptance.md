# M20 Original ES2 Alpha 驗收

> Alpha（內部初期可玩版）：核心流程已可實際執行，但內容尚未達完整正式版。

## 必須由真實 Runtime 通過

- Driver（驅動程式，用來執行 MUD）可編譯並啟動。
- Client（連線端）可連上本機測試 Server（伺服器）。
- 可建立 `human + commoner + level 1` Original 測試角色。
- 角色可進入客棧大堂，執行 `look`、`score`、`inventory`。
- 角色可向西移動到廚房，再向東返回客棧大堂。
- `quit` 後可用同一帳號重新登入，且不會再次進入創角流程。

## 證據邊界

M20 PASS 只代表 Original ES2 Alpha 的最小可玩旅程通過；M21～M25 的完整內容、資料考證與長時間穩定性仍未完成。ES2-KING Expansion（擴充內容）不參與本驗收。
