# Original ES2 Race Database

本目錄保存《東方故事2：天朝帝國》（ES2）
Original Race 種族系統的考證資料。

## 核心原則

本資料庫以 Annihilator / Original ES2 為最高優先來源。

不得因資料缺失而自行創造 Original ES2 的種族設定。

所有資料依證據標記：

- [Confirmed] 原始碼或原始文件確認
- [Archived] ES2 歷史資料確認
- [Variant-US] 北美版本資料
- [Player Memory] 專案擁有者原版遊玩記憶
- [Unverified] 尚待確認
- [ES2-KING Expansion] ES2-KING 新創

# Race Research Checklist

每一個 Race 最終至少需要完成以下考證：

- Original ID
- 中文名稱
- Race Object / Source File
- 種族背景
- 出生設定
- 天生 Attribute
- Attribute Bonus / Penalty
- Kee / Gin / Sen 影響
- 特殊能力
- 特殊 Command
- 特殊物件
- 職業適性
- Class 限制
- Guild / Clan 限制
- Skill Bonus
- Combat Bonus
- Lifecycle 特性
- 死亡相關機制
- 業力需求
- 創角條件
- 版本差異

# Original ES2 Preservation Rule

Original ES2 Race 資料只負責：

保存
→ 考證
→ 重建
→ 驗證

不得在本目錄直接加入 ES2-KING 新創能力。

任何新增種族或新能力必須放入：

es2_king_expansion/

並標記：
